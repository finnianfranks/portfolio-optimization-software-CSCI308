RESEARCH INTO HOW TO BUILD A SHARPE RATIO:
- compare an investments returns with it's risk
- numerator: realized or expected returns - benchmark (e.g. risk-free rate of return)
- denominator: standard deviation of returns over the same period
- the reward to variability ratio. 
- Sharpe Ratio = (Rp - Rf) / sd(p)
    - Rp = return of portfolio
    - Rf = risk free rate
    - sd(p) standard deviation of portfolio's excess returns
- the SD derived from variability of returns for a series of time intervals (summation?)
- numerator: average of return differentials in each of the incremental periods making up the total
    - e.g. 10 year sharpe ratio -> avg 120 monthly return differentials
    - in the same example denominator is SD of those monthly returns
Denominator: 1. Take the return variance from the average return in each of the incremental periods, square it, and sum the squares from all of the incremental periods.
             2. Divide the sum by the number of incremental periods.
             3. Take the square root of the quotient.
- risk free rate: investors hypothetical minimal borrowing cost
- the ratio assumes that the historical record of returns has some predictive value
    - NVDIA crashing because of jensen huang is not predictable
- Generally the higher the sharpe ratio the more attractive the risk adjusted return
- negative ratio means benchmark rate is greater than portfolios historical or projected return
- for this project we use historical returns
- longer return measurement intervals means lower estimate of volatilty
    - practed if a portfolio manager wants to manipulate their ratio to be better
- we typically consider the volatility of monthly returns
- we don't want to cherry pick, we want to stay objective in our historical look back 
- US treasure bond yields are a proxy for the risk-free rate of return
